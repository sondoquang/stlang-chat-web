# Project Name

## Project Description

This project is a web application built using React and Firebase. The project was created to facilitate rapid communication among team members.

## Installation

1. Clone the repository: `https://github.com/sondoquang/stlang-chatapp.git`
2. Navigate to the project directory: `cd stlang-chatapp`
3. Install dependencies: `npm install`
4. Set up the database: `npm run dev`

## Usage

1. Open your web browser and navigate to `http://localhost:3000`
2. Sign up or log in to start using the application.
3. Create new tasks and projects, or manage existing ones.
4. Customize the application by modifying the source code.

## Features

- User authentication and authorization
- Task management (create, update, delete)
- Project management (create, update, delete)
- Drag and drop functionality for reordering tasks
- Responsive design for mobile and desktop

## Technologies Used

- React
- Node.js
- Firebase
- React Router
- Axios
- Ant Design
